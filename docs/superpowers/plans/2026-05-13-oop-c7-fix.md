# OOP Course 7 Fix — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate OOP Course 7 (STL — 6 sections) from `Course07.jsx` to a JSON course at `course-07.json` that matches `oop-c8`–`oop-c11` pedagogy (quiz blocks with per-option explanations, trap callouts), normalize id to `oop-c7`, and shim legacy `checked` localStorage keys onto the new `progress` keys so existing classmates do not lose section progress.

**Architecture:** Six-stage `/curate` pipeline emits `course-07.json` from the existing `Course-7.pdf` source. Registry entry in `src/content/oop/index.js` swaps from `{ id: oop-course_7, sections: [], component: lazy(...) }` to `{ id: oop-c7, metaId, src }`. A one-shot `useEffect` in `AppContext.jsx` reads the ordinal mapping of legacy section ids → new step ids (captured during plan execution) and writes them into the `progress` map under a `migrated_oop_c7=1` sentinel. After deploy, one Gemini-driven review round (clone of `scripts/review-gemini-oop-c11.mjs`) catches content gaps.

**Tech Stack:** React 19, Vite 8, Tailwind v4. Curate pipeline: Gemini (extraction) + Opus (drafting/review). Validators: `scripts/validate-course-json.mjs`, `scripts/validate-bilingual.mjs`, `scripts/lint-site.mjs`, `scripts/smoke-test.mjs`. Review: `scripts/review-screenshot.mjs` + `scripts/review-gemini-oop-c11.mjs` (cloned for c7).

**Spec:** `docs/superpowers/specs/2026-05-13-oop-c7-fix-design.md`

## Task 8: Add localStorage shim to AppContext

**Files:**
- Modify: `src/contexts/AppContext.jsx` (insert helper near lines 8-37; insert useEffect near lines 112-140)

- [ ] **Step 1: Add the migration helper near the existing helpers**

Open `src/contexts/AppContext.jsx`. After the `migrateLabKeys` function (line 37), insert:

```js
/** One-time migration: legacy oop-course_7-* section checks → oop-c7-* progress entries.
 *  Mapping is by topic (ordinal across the six content sections), captured during the
 *  Course 7 JSON migration (2026-05-13). Returns { removeFromChecked, addToProgress } or null. */
function migrateOopC7Keys(checked) {
  const map = {
    'oop-course_7-sequence':   '<STEP_ID_FOR_SEQUENCE>',
    'oop-course_7-adaptors':   '<STEP_ID_FOR_ADAPTORS>',
    'oop-course_7-streams':    '<STEP_ID_FOR_STREAMS>',
    'oop-course_7-strings':    '<STEP_ID_FOR_STRINGS>',
    'oop-course_7-init-lists': '<STEP_ID_FOR_INIT_LISTS>',
    'oop-course_7-iterators':  '<STEP_ID_FOR_ITERATORS>',
  };
  const removeFromChecked = [];
  const addToProgress = {};
  let any = false;
  for (const [oldK, newK] of Object.entries(map)) {
    if (checked[oldK]) {
      removeFromChecked.push(oldK);
      addToProgress[newK] = { visited: true, understood: true };
      any = true;
    } else if (oldK in checked) {
      // Key exists but is falsy — drop it; do not propagate to progress.
      removeFromChecked.push(oldK);
      any = true;
    }
  }
  return any ? { removeFromChecked, addToProgress } : null;
}
```

Replace each `<STEP_ID_FOR_*>` placeholder with the actual JSON step id from `docs/superpowers/plans/notes/c7-step-ids.md` (Task 3 output).

- [ ] **Step 2: Add the useEffect inside AppProvider**

In `src/contexts/AppContext.jsx`, after the existing `progress_v1_migrated` useEffect (around line 140), insert:

```jsx
  // One-time migration: legacy oop-course_7-* checked keys → oop-c7-* progress entries.
  // Added 2026-05-13 with the Course 7 JSON migration. Sentinel-gated. Idempotent.
  useEffect(() => {
    if (localStorage.getItem('migrated_oop_c7') === '1') return;
    try {
      const result = migrateOopC7Keys(checked);
      if (result) {
        const { removeFromChecked, addToProgress } = result;
        setChecked(prev => {
          const next = { ...prev };
          for (const k of removeFromChecked) delete next[k];
          return next;
        });
        setProgress(prev => ({ ...prev, ...addToProgress }));
      }
      localStorage.setItem('migrated_oop_c7', '1');
    } catch (e) {
      console.error('oop-c7 shim failed', e);
    }
  }, []); // eslint-disable-line react-hooks/exhaustive-deps
```
