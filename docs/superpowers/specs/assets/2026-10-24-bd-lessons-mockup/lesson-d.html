Pui aceeași întrebare fiecărui rând („e din anul 1?”) și păstrezi doar rândurile unde răspunsul e „da”. Uite cum arată asta în SQL.

Ce face WHERE cu fiecare rând

SELECT nume, bursa
FROM studenti
WHERE an = 1
ORDER BY nume;
Atenție: NULL nu e 0. Bursa Anei e NULL, adică „nu se știe”. Imediat vezi de ce contează.

Cum se scrie

SELECT coloane
FROM tabel
WHERE condiție
ORDER BY coloană;
condiție = o întrebare cu răspuns „adevărat” sau „fals”, pusă fiecărui rând.
WHERE păstrează doar rândurile unde răspunsul e „adevărat”.
Se scrie începând cu SELECT, dar se execută în ordinea FROM → WHERE → SELECT → ORDER BY.

Capcana NULL

Ana chiar nu are bursă. Atunci de ce WHERE bursa = NULL nu o găsește?

Pentru că NULL înseamnă „nu se știe”. „Nu se știe = nu se știe” dă tot „nu se știe”, nu „adevărat”. WHERE păstrează doar „adevărat”, deci Ana iese. De asta există IS NULL: e singura întrebare care primește „da” pentru o valoare lipsă.

Care interogare afișează studenții din anul 1 care nu au bursă?

Adăugat la recapitulare. Revine mâine ca exercițiu nou.

Afișați numele studenților din anul 1 care au bursă, ordonați după nume.

Două condiții adevărate în același timp, apoi sortare. „Are bursă” e opusul lui „nu se știe”.
AND între condiții, IS NOT NULL pentru „are”, ORDER BY la final.
SELECT nume FROM studenti
WHERE an = 1 AND bursa IS NOT NULL
ORDER BY nume;
