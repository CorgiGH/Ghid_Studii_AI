### L5. Distribuții comune, marginale, condiționate; independența variabilelor; covarianță (`ml-l05`, priority A)

**Concepts:** C5.1 Distribuția comună, marginalele, distribuțiile condiționate; regula de înlănțuire pentru 3 variabile; C5.2 Independența variabilelor aleatoare (pe toate perechile de valori); C5.3 Covarianța, coeficientul de corelație, Var(X+Y).

**Definitions / notation:** Distribuția comună p(x,y); Marginalele p_X(x)=Σ_y p(x,y); Distribuția condiționată p_{X|Y}(x|y)=p(x,y)/p_Y(y); Independența v.a.: p(x,y)=p_X(x)p_Y(y) pentru toate perechile; Covarianța Cov(X,Y)=E[(X−EX)(Y−EY)]; Coeficientul de corelație ρ=Cov/(σ_Xσ_Y).

**Properties:** Cov(X,Y)=E[XY]−E[X]E[Y]; Var(X+Y)=Var X+Var Y+2Cov; X,Y independente ⇒ E[XY]=E[X]E[Y] și Cov=0; Cov=0 nu implică independența; pentru variabile {0,1}, Cov=0 ⇔ independente; −1 ≤ ρ ≤ 1; |ρ|=1 ⇔ Y liniară în X; Pentru independente: Var(X+Y)=Var X+Var Y; 0.13: șapte numere libere pentru 3 booleene; o listă specifică joint-ul dacă determină lanțul P(Z)P(X|Z)P(Y|X,Z); Pentru binare cu parametrii α,β,γ,δ: independente ⇔ αδ=βγ (0.99).
